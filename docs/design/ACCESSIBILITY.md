# Accessibility
Android minimum interaction target 48 dp; web 44 px or larger with spacing. Label icon actions, associate labels/errors with fields, support font scaling, preserve focus after errors/dialogs and keep state understandable without color. Quran text must preserve shaping/diacritics at large sizes and RTL boundaries. TalkBack reads source/reference and counter state without announcing every audio frame.

Verify Arabic/English, compact/tablet/landscape, light/dark, 1.5× font size, keyboard admin navigation, visible focus and accessible chart summaries. Password visibility, OTP autocomplete and loading/disabled states must be operable. Never remove zoom or suppress focus to achieve a visual style.
