# Brand guidelines
Use the supplied `assets/athar-official.png` unchanged as the source asset. It is RGBA, 1536×1024. Its SHA-256 is recorded in the file inventory. Existing cropped web logo/icon assets remain until visual comparison confirms an approved replacement. Never draw a substitute wordmark, append duplicate أثر text or recolor to a new brand.

Use aspect-ratio-preserving rendering, conservative optical size and accessible label أثر/Athar. App adaptive icons need safe foreground insets, while splash follows platform behavior rather than holding an artificial loading screen. Preserve license notices for fonts/models separately from the brand asset. Green, warm ivory and copper remain the product identity in both language directions.
