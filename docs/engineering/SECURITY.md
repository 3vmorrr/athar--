# Security engineering
Enforce actor and resource policy on the server. Require HTTPS for mobile/release admin; local development exceptions must be build-only and never shipped. Web cookie writes require CSRF; bearer requests never accept a user-supplied owner as authority. Secrets and tokens are hashed/encrypted appropriately, never logged or returned in read APIs. Refresh replay revokes the token family, password changes revoke sessions and shared rate windows resist cookie resets.

Validate uploads by MIME/signature/dimensions/size; store opaque keys outside public and use controlled access. Provider calls use a fixed allowlist, TLS verification, byte/time bounds and no arbitrary client URL fetch. Output text is escaped. Backups are authenticated encrypted archives with checksum/schema validation and owner step-up. No production reset route. Night Prayer logs are owner-private; exempt information stays local. Review database privileges and supported server versions before public deployment.
