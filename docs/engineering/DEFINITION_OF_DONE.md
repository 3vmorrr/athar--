# Definition of done
IMPLEMENTED means code exists with a concrete behavior; TESTED means named relevant checks executed and evidence exists; VERIFIED means acceptance passed end to end in the intended environment. Blocked provider/device/hosting steps remain BLOCKED, not successful.

Release needs a native build and real authenticated API journey, complete existing-feature migration, independent authorized admin CRUD, both languages/directions, accurate canonical Quran/source data, local/private recitation policy, complete Night Prayer offline/edit/sync/analytics/privacy behavior, meaningful security tests, measured release performance, lawful dependencies and reproducible deployment. No placeholder screen is accepted as a completed feature. No test result or user activity is fabricated.
