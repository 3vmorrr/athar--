# User journeys
First run: platform splash → 3–4 concise branded onboarding pages → sign in/register → successful email OTP verification → home. Returning verified users restore a revocable session; failed refresh returns to authentication. Network failure preserves permitted offline data without inventing a successful login.

Quran: choose read/listen/tafsir/search/review → select scope → open canonical reference → bookmark/resume explicitly. Audio playback has its own controls; switching reciters replaces stale timing results. Learning: scholar → series → ordered lesson → official YouTube fallback if needed → private resume and moderated first-party comments. Adhkar: category → one readable entry → persisted counter → next entry.

Night Prayer: target or inclusive range calculator → explicit planned session → optional pauseable timer → confirm self-reported completion → immutable night context snapshot → local history/analytics → idempotent sync. Edits/deletions recompute totals and continuation. Private exemptions are optional/local and do not inflate prayer totals. Administration: independent login → authorized section → validated mutation → one feedback message → audit event.
