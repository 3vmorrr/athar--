# Future features
The approved Night Prayer module is current scope, not a future optional idea. Potential later extensions include additional approved tafsir editions, supported audio downloads, optional protected cross-device exemption sync, more granular editorial roles and reporting workflows. Each requires a feature specification, provider/license check, API contract, migration if necessary and tests.

Do not add social rankings, advertising, paid tiers or server microphone uploads under an extension. Keep extension modules separated into UI/state, domain rules, repository, backend route/policy and test evidence.
